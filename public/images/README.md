# Imagen de perfil

Colocá tu foto aquí con el nombre exacto:

**`profile.jpg`**

- Ruta completa: `public/images/profile.jpg`
- En el sitio se sirve como: `/images/profile.jpg`
- Formatos: JPG o JPEG recomendado; si usás PNG, renombrá a `profile.png` y actualizá la constante `PROFILE_SRC` en `src/components/ProfilePortrait.tsx`.

Proporción sugerida: retrato vertical (por ejemplo 4:5), al menos **800×1000 px** para que se vea nítida en pantallas retina.

No es obligatorio subir la imagen al repositorio: podés añadirla solo en tu máquina o usar `.gitignore` para `profile.jpg` si preferís no publicarla en GitHub.
